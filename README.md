# QMK configurations

A repo to keep track of my QMK configuration, using [QMK userspace].

## Setup

Until I [package the firmware within the flake][qmk-flake]:

```shell
qmk setup --home ./.firmware/
```

[QMK userspace]: https://docs.qmk.fm/newbs_external_userspace
[qmk-flake]: https://discourse.nixos.org/t/flashing-qmk-keyboard-with-nix/42217/6
